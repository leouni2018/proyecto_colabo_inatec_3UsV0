Curso de Git y GitHub

Git permite registrar y administrar los cambios de un proyecto. GitHub facilita alojar repositorios y colaborar mediante ramas, revisiones y solicitudes de integración.

01

Control de versiones

Comprender repositorios, commits, historial y recuperación de cambios.

02

Trabajo con ramas

Desarrollar mejoras de manera independiente sin afectar la rama principal.

03

Colaboración

Compartir cambios, revisar Pull Requests y resolver conflictos.
