# Tablero de tareas del equipo

## Usuario 1 — Coordinación e integración
- [ ] Crear repositorio remoto.
- [ ] Subir estructura inicial a `main`.
- [ ] Invitar a Usuario 2 y Usuario 3.
- [ ] Revisar Pull Request de contenido.
- [ ] Revisar Pull Request de diseño.
- [ ] Integrar cambios y comprobar el sitio.

## Usuario 2 — Contenido académico
- [ ] Crear `feature/contenido` desde main actualizado.
- [ ] Mejorar descripción del curso.
- [ ] Agregar objetivos de aprendizaje.
- [ ] Ampliar temario con los temas realmente impartidos.
- [ ] Revisar ortografía.
- [ ] Hacer commit, push y abrir Pull Request.

## Usuario 3 — Diseño y presentación
- [ ] Crear `feature/diseno` desde main actualizado.
- [ ] Ajustar colores y tipografía.
- [ ] Mejorar espaciados y tarjetas.
- [ ] Verificar adaptación móvil.
- [ ] Probar en navegador.
- [ ] Hacer commit, push y abrir Pull Request.

## Criterios de aceptación
- [ ] La página abre sin errores.
- [ ] Los enlaces del menú funcionan.
- [ ] El diseño se adapta a pantallas pequeñas.
- [ ] Los cambios se integraron mediante Pull Requests.
- [ ] El equipo explica clone, branch, commit, push, pull, merge y Pull Request.
