# Proyecto colaborativo INATEC — Git y GitHub

Página web estática para practicar colaboración entre tres participantes usando Git, GitHub y Visual Studio Code.

## Objetivo
Practicar repositorios, commits, ramas, push/pull, Pull Requests, revisión de cambios y resolución de conflictos.

## Tecnologías
HTML5 · CSS3 · Git · GitHub · Visual Studio Code

## Estructura
- `index.html`: estructura y contenido de la página.
- `css/styles.css`: diseño visual y adaptación móvil.
- `docs/GUIA_COLABORATIVA.md`: procedimiento completo del equipo.
- `docs/TAREAS_EQUIPO.md`: reparto de actividades.
- `docs/PLANTILLA_PULL_REQUEST.md`: formato sugerido para PR.

## Ejecutar
Abre `index.html` directamente en el navegador o utiliza Live Server en VS Code.

## Equipo
Sustituye Usuario 1, Usuario 2 y Usuario 3 por los nombres reales.
